# ChronoTech
PWA estática (HTML + JS). Requiere tu propia clave de API de Google Gemini (se guarda solo en tu navegador).

## Publicar en GitHub Pages
1. Sube todos los archivos a la raíz de un repositorio.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`.
3. Abre `https://TU_USUARIO.github.io/TU_REPO/`, pulsa el engranaje y pega tu clave.
4. Al actualizar, cambia `V` en `sw.js` (p. ej. `chronotech-v2`) para renovar la caché.
